# Master ID 显式设为 0x10 + 电机 ID

电机回帧用的 CAN ID 由寄存器 0x07（Master ID）决定，出厂默认 0。若 6 个电机都保持默认，所有反馈都会落在同一个 ID `0x000`，只能靠 payload 的 D[0] 低半字节区分，且厂商文档明确要求不要把 Master ID 设为 0。本工程把每个电机的 Master ID 定为 `0x10 + 电机 ID`（`0x11`–`0x16`），既让回帧 ID 唯一，也让固件可以用硬件滤波器把它们和命令帧分开。

## Consequences

- 固件仍保留"按 payload 低半字节兜底匹配"的分支，因为现场电机可能还是出厂默认值——两条路都收，不靠假设。
- 电机换新或改 ID 时，Master ID 必须跟着改，否则反馈会落到别的 ID 上。
